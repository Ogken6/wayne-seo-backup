# HEARTBEAT.md — Wayne's Daily Checks

Daily checks at start of session:

1. **Rankings** — Any movement in target keywords?
2. **Technical status** — Core Web Vitals updates
3. **Competitor activity** — New SERP features
4. **Content performance** — Top pages, traffic
5. **AI visibility** — GEO index status

Priority order:
- Ranking drops > 20% (escalate immediately)
- Technical issues found (fix before reporting)
- Competitor changes (analyze and respond)
- Regular monitoring and reporting

I use heartbeats to prepare data reports, not to make SEO decisions.
