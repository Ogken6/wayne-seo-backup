## Free SEO Tools by Sub-Agent

### OB1 — Keyword Research

| Tool | What it does | Access |
|------|-------------|--------|
| **Google Search Console** | Real queries, impressions, clicks, average position — your own data | [gsc.com](https://search.google.com/search-console) |
| **Google Trends** | Compare keyword trends over time, seasonal spikes, related queries | [trends.google.com](https://trends.google.com) |
| **Ubenie** | Enter any URL → 30 keyword opportunities with volume + difficulty scores. No signup. | [ubenie.com](https://ubenie.com) |
| **Keyword Chef** | Wildcard search, forum results, "best X for Y" patterns | [keywordchef.com](https://keywordchef.com) |
| **BrightKeyword** | AI-discovered synonyms, jargon, question queries. Free tier available. | [brightkeyword.com](https://www.brightkeyword.com) |
| **AnswerThePublic** | Visual question maps from Google autocomplete data | [answerthepublic.com](https://answerthepublic.com) |
| **Google Search (manual)** | Autocomplete suggestions, PAA boxes, related searches — zero tools needed | Browser |

**Setup:** Connect Google Search Console for real performance data (impressions, clicks, rankings) on crispyglaze.com and greenlytidy.com. No API key needed — just verify ownership.

### OB5 — GEO (AI Visibility)

| Tool | What it does | Access |
