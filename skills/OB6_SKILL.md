1. **TikTok first** (weekly): Search seed terms, note trending video titles and comment questions
2. **Google Trends validation**: Check if TikTok trend is reflected in search interest
3. **Ubenie check**: Run on crispyglaze.com to see if we already have content for trend
4. **Competitor scan**: See if major food blogs have covered the trend

### Reddit Research (Monthly)
- Search: r/Cooking, r/recipes, r/FoodPorn for repeated questions
- Find: "What's the best way to...?", "Why does my X always...?", "X vs Y for..."
- Convert: Questions → recipe content topics

## OB6 Workflow

### Step 1: Trend Scanning (Weekly)
- Search TikTok for 5 seed terms relevant to crispyglaze.com (cucumber, Asian, salad, sauce, etc.)
- Note: Trending video titles, comment questions, creator language
- Check Google Trends: Is search interest rising for TikTok trends?
- Log emerging trends with date discovered

### Step 2: Content Gap Analysis
- Run Ubenie on crispyglaze.com → get existing keyword list
- Run Ubenie on top 3 competitors → get their keyword lists
- Compare: Which trending topics do we NOT have content for?
- Flag: High-trend + low-competition = priority content opportunity

### Step 3: Recipe Keyword Discovery
- Use KitchenSEO modifier patterns:
  - Ingredient + method: "cucumber air fryer", "cucumber ferment"
  - Ingredient + dietary: "cucumber keto", "cucumber vegan", "cucumber gluten-free"
  - Ingredient + occasion: "cucumber summer salad", "cucumber party recipe"
  - Ingredient + cuisine: "cucumber Korean", "cucumber Japanese", "cucumber Thai"
- Use AnswerThePublic for question variations
- Use YouTube autocomplete for video content opportunities

### Step 4: Seasonal Planning
- Use Google Trends 12-month view for target keywords
- Identify: Seasonal spikes (Thanksgiving, summer, Chinese New Year, etc.)
- Plan: Content 3–6 months before seasonal peak
- Create content calendar with recipe opportunity windows

### Step 5: Recipe Schema Opportunity Scan
- Run Google Rich Results Test on existing recipe pages
- Identify: Which pages are NOT eligible for rich results
- Fix: Missing fields → OB2 for schema implementation
- Find: Pages missing nutrition, video, or aggregateRating

### Step 6: Competitive Recipe Content Analysis
- Run Ubenie on: kirbiecravings.com, recipetineats.com, thewoksoflife.com
- Find: Recipe types they have that crispyglaze.com doesn't
- Note: Content format (video, long-form, quick-print), schema type, cuisine focus
- Create: "Recipe Gap Priority List" for OB4

### Step 7: Deliver Output
- Trending recipe topics (TikTok + Google Trends)
- Content gap list (competitor vs crispyglaze.com)
- Seasonal content calendar (next 6 months)
- Recipe schema opportunities (pages missing rich results)
- Top 10 recipe content opportunities ranked by trend + opportunity + competition
