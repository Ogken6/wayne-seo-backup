### Manual SERP Analysis (No Tool Needed)
- Search target keyword in Google (incognito)
- Screenshot top 5 results with titles, URLs, meta descriptions
- Note PAA box questions
- Note featured snippet format (paragraph vs list vs table)
- Note image/video carousels
- Identify what content format Google rewards

### Competitor Research
- Run Ubenie on competitor URL → get their top 30 keywords
- Cross-reference with crispyglaze.com keyword list → find gaps
- Run Neil Patel SEO Analyzer on main keyword → see top 10 with authority scores
- Use BuzzSumo to find what content gets most shares → validate content type

### Usage Notes
- **SERP features** are tracked manually — Google Search shows all features in results
- **Volatility** = check same keyword in Google weekly, record position changes
- **Gap analysis** = Ubenie on competitors + GSC data on crispyglaze.com = keyword gaps

## OB3 Workflow

### Step 1: SERP Feature Scan
- Open Google Search → target keyword (incognito)
- Identify all SERP features present: AI Overview, PAA, featured snippet, video, image pack, local
- Note which features appear and which competitors own them

### Step 2: Competitor Keyword Gap Analysis
- Run Ubenie on: kirbiecravings.com, jessicagavin.com, thewoksoflife.com, justonecookbook.com
- Export top 30 keywords for each competitor
- Cross-reference against crispyglaze.com current rankings (from GSC)
- Flag: keywords competitors rank for that crispyglaze.com does NOT

### Step 3: Content Format Analysis
- Look at top 5 ranking pages for target keyword
- Note: Article length, header structure, image count, schema type, word count
- Identify what Google rewards (how-to? Recipe? List? Video?)
- Flag opportunities to create content that matches or beats format

### Step 4: Ranking Factor Research
- Run Neil Patel SEO Analyzer on target keyword
- Note domain authority of top 10
- Note page age of top results
- Note backlink counts of top 3

### Step 5: Volatility Monitoring
- Track keyword positions weekly (use GSC for crispyglaze.com own queries)
- For competitors' keywords: manually check position 1x/week
- Flag any SERP instability (frequent position changes, new entrants)

### Step 6: Deliver Output
- SERP feature map for target keyword
- Competitor gap analysis: keywords crispyglaze.com should target
- Content format recommendations (what to create and how)
- Top 5 SERP opportunities ranked by difficulty vs reward
